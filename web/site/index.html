k8s-dev-lab

This page is served by the web Deployment in the devapp namespace: an nginx container built from web/, imported into containerd on each worker, and exposed on NodePort 30081. It proxies /api/ to the FastAPI service.

  • /api/healthz — API liveness; shows which pod answered
  • /api/readyz — API readiness (checks Postgres)
  • /api/notes — notes stored in Postgres
  • /docs — Swagger UI
  • /healthz — this nginx

Try it

curl -s -X POST http://192.168.56.11:30081/api/notes \
  -H 'Content-Type: application/json' -d '{"text":"from the site"}'

Paths a request can take

browser → web VM (192.168.56.20, nginx edge) → NodePort 30081 → web pod → api Service → api pod → postgres
browser → NodePort 30081 on any worker      → web pod → api Service → api pod → postgres
browser → NodePort 30080 on any worker      → api pod → postgres
